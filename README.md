My nvim setup for embedded projects

to use it:

```bash
rm -fr ~/.config/nvim
git clone https://github.com/pcbden/nvim.git ~/.config/nvim
```

Dont forget to backup your config if you have one

To use debug start openocd in another terminal

If you are first time installing(using) nvim:

1) install nvim (0.11.x or later)
2) install plug
3) install nodejs npm
4) open nvim and do :PlugInstall and reopen nvim
